## 💡 Puntos Clave a Recordar

::: {.callout-tip}
### Los 5 conceptos más importantes

1. **Sistema Operativo = Intermediario hardware/software**  
   Sin SO, no funciona nada. Todo pasa a través del SO.

2. **Kernel ≠ Shell**  
   Kernel gestiona hardware (invisible). Shell es la interfaz (lo que ves).

3. **Linux = Kernel + Distribución**  
   El kernel es igual, pero cada distro agrega herramientas diferentes.

4. **Ubuntu 22.04 LTS = 5 años de soporte**  
   LTS significa Long Term Support - garantía hasta Abril 2027.

5. **GPL = Libertad de código abierto**  
   Puedes usar, estudiar, modificar y distribuir Linux gratuitamente.

:::
