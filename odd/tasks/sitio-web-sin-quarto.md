  - UNIDAD V: Gestión de Procesos y Logs — 5.1. Systemd units y Journalctl / 5.2. Cron/anacron y At / 5.3. Diagnóstico de consumo de recursos (htop) en tiempo real
  - UNIDAD VI: Redes y Almacenamiento Local — 6.1. Resolución DNS / 6.2. Entender puertos (localhost) / 6.3. NAT y volúmenes lógicos básicos / 6.4. Particiones clásicas y LVM / 6.5. Montaje persistente y Fstab
  - UNIDAD VII: Seguridad Práctica (Hardening) — 7.1. Configuración de Firewall (UFW) / 7.2. Fail2Ban
  - UNIDAD VIII: Introducción a Docker — 8.1. Instalación de Docker Engine / 8.2. Correr "Hola Mundo"
  - UNIDAD IX: Nginx como Servidor Web y Proxy — 9.1. Configuración de alto rendimiento / 9.2. Servir una página HTML estática localmente
  - UNIDAD X: Certificados SSL y HTTPS (Certbot) — 10.1. Seguridad web real con Let's Encrypt / 10.2. Configurar redirecciones forzadas de HTTP a HTTPS
  - UNIDAD XI: Bases de Datos en Contenedores y despliegue de Aplicación — 11.1. Levantar MySQL/PostgreSQL con Docker en segundos / 11.2. Unir Nginx (Proxy) / 11.3. App + DB usando Docker Compose
