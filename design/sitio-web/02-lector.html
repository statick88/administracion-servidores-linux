Unidad VIII · Introducción a Docker

Corre tu primer contenedor

Objetivos de la unidad
  • Instalar Docker Engine en tu entorno Linux.
  • Ejecutar el clásico "Hola Mundo" y entender qué pasa por dentro.

8.1 Instalación de Docker Engine

En Ubuntu/Debian el paquete oficial se instala desde el repositorio de Docker. Verifica la firma del repositorio antes de confiar en él:

sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io
docker run --rm hello-world

La salida confirma que tu demonio responde y que el flujo completo — pull, creación y ejecución del contenedor — funciona.

8.2 Correr "Hola Mundo"

Cada contenedor nace de una imagen: una plantilla de solo lectura. La primera ejecución la descarga; las siguientes la reutilizan.

docker run hello-world
docker images
docker ps -a

Comprobación

  • docker images lista las imágenes locales.
  • docker ps -a muestra contenedores en ejecución y detenidos.
