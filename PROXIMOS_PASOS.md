## 🎯 PROYECTO FINAL SUGERIDO

> **Actualizado:** el proyecto final ya está publicado con entregable y rúbrica en [`unidades/unidad12/7_proyecto_final.qmd`](unidades/unidad12/7_proyecto_final.qmd) (Unidad XII del brochure). La propuesta de abajo es la versión original.

**Objetivo:** Configurar un servidor empresarial completo para la empresa

**Requisitos:**
1. Instalación limpia de Ubuntu/CentOS
2. Usuarios de administrador y usuarios normales
3. Servicios: Web (Apache/Nginx), SSH, FTP
4. Firewall configurado y seguro
5. Backup automático
6. Monitorización activa
7. Documentación completa

**Evaluación:**
- 50% Funcionalidad técnica
- 30% Seguridad e implementación
- 20% Documentación y presentación

## 🔧 TROUBLESHOOTING PROACTIVO

### Problemas Anticipados

**Problema 1: Estudiante atrasa con Lab 1**
- Solución: Sesión catch-up 1-a-1 (30 min)
- Recurso: Guía acelerada de Lab 1

**Problema 2: Dificultad con permisos de Linux**
- Solución: Ejercicios adicionales, pequeña rueda de referencia
- Recurso: Cheat sheet de permisos (crear)

**Problema 3: VM no funciona en equipo del estudiante**
- Solución: Usar servicio cloud (AWS free tier, DigitalOcean, etc.)
- Recurso: Tutorial para alternativas

**Problema 4: Ritmo muy rápido/lento**
- Solución: Ajustar según feedback
- Recurso: Contenido adicional preparado
